# Переказ: тренажёр на украинском (MVP: «Щасливий принц»)

Спецификация для Claude Code. Пишем в новом публичном репозитории `pereskaz-trainer`, GitHub Pages.

## 0. Для Claude Code: как работать

- Общайся с владельцем проекта (Кондрат) по-русски, коротко.
- Сначала прочитай этот файл целиком. Потом создай `CLAUDE.md` с правилами проекта и закоммить.
- Вопросы задавай пачками по 3–5, к каждому давай рекомендуемый ответ. Ответы записывай в `docs/DECISIONS.md`.
- Продакшн-код не пиши, пока не сделан и не одобрен мокап первого экрана (раздел 6).
- Не клади в репозиторий имя ребёнка, его фото, возраст, результаты и любые персональные данные. Ребёнка в коде называй «Игрок».
- Не клади в репозиторий текст и иллюстрации из учебника (см. раздел 2). Весь текст сказки пишем сами, короткими пересказами.

## 1. Цель и пользователь

Игрок учится пересказывать литературный текст по-украински. Сейчас у него трудности: он может перепутать персонажей (например, ластівку и дівчинку), не отвечает на вопросы по тексту и не может пересказать по порядку.

Пользователь: Игрок, украинский язык. Занимается с мамой (она читает сказку вслух). Тренажёр дополняет чтение вслух, а не заменяет его.

Главный результат MVP: по картинке игрок называет персонажа и отвечает на вопросы о нём, а потом пересказывает сказку по сценам.

## 2. Источник и авторские права

Материал взят из учебника «Українська література, 5 клас» (файл `5_lit_2022-1.pdf`, стр. 112–121, «Щасливий принц», переклад І. Корунця, скорочено).

- Сам текст перевода и иллюстрации учебника в репозиторий не кладём.
- Сюжет сказки взят из оригинала Оскара Вайльда (1888), он в публичном достоянии.
- Все подсказки, сцены и вопросы пишем сами простым украинским языком. Имена персонажей и предметов берём из оригинала.
- Картинки рисуем сами (простой SVG, плоские иконки) или используем свои фото. Для каждого персонажа одна картинка.

## 3. Сюжет: 8 сцен

Сцены короткие: одна сцена, один кадр, одна-две фразы пересказа. Каждую сцену делаем в трёх вариантах: картинка, эталонный пересказ (одна фраза), вопросы.

1. **Статуя.** Над містом стоїть статуя Щасливого принца. Він весь у листочках золота, очі — сапфіри, на руків'ї шпаги рубін. Міський радник: «Він прекрасний, але користі мало».
2. **Ластівка і Очерет.** Ластівка відстала від подруг, які полетіли до Єгипту. Вона закохалась в Очерет. Очерет не хоче летіти, і Ластівка летить сама.
3. **Ніч під статуєю.** Ластівка хоче спати під статуєю, падає дощ. Принц плаче: він бачить бідність міста.
4. **Рубін для кравчині.** Принц просить віднести рубін з його шпаги бідній швачці. У неї хворий синок, якому потрібні апельсини. Ластівка виконує прохання.
5. **Очі.** Принц просить віднести одне око юнакові-драматургу в мансарді, а друге дівчинці, яка продає сірники. Ластівка віддаёт обидва сапфіри.
6. **Зима.** Принц весь без золота. Ластівка роздаёт листочки золота бідним, діти радіють. Настає зима, Ластівка замерзає біля принца.
7. **Статую знесли.** Мер міста і радники бачать статую без золота і вирішують її переплавити. Серце не плавиться, його викидають на сміття разом із мертвою ластівкою.
8. **Бог і ангел.** Бог велить ангелу принести дві найцінніші речі міста. Ангел приносить свинцеве серце і мертву пташку. Бог каже: «Ти правильно вибрав».

## 4. Персонажі та предмети (картки)

Персонажі (картка з картинкою і ім'ям): Щасливий принц (статуя), Ластівка, Очерет, Мер міста, Міські радники, Кравчиня (швачка), Синок кравчині (хлопчик), Драматург (юнак), Дівчинка з сірниками, Професор орнітології, Ангел, Бог.

Предмети: золото (листочки), сапфір (очі), рубін, сірники, апельсини, свинцеве серце, мертва пташка.

Пари, які легко плутати (їх тренуємо окремо): Ластівка / Дівчинка, Принц / Мер, Кравчиня / Дівчинка з сірниками, Очерет / Ластівка.

## 5. Режимы и вопросы (MVP)

Уровни вопросов по каждой сцене:

- **L1. Хто це?** Показываем картинку, спрашиваем «Хто це?». Ответ голосом или выбором из трёх карточек.
- **L2. Що робить?** «Що робить Ластівка?» Ответ одним словом или фразой.
- **L3. Чому / Що відчуває?** «Чому Принц плаче?» Ответ фразой. Подсказка: «Бо бачить бідність».
- **L4. Що було спочатку / потім?** Порядок сцен: выбрать из 3 картинок, поставить в порядке.
- **L5. Переказ.** Игрок пересказывает сцену своими словами. Подсказки: картинка, первое слово, вопрос L3.

Режим «Пари»: две похожие карточки рядом, вопрос «Це хто?», ответ с подсказкой по признаку («у неї крила», «вона дівчинка»).

Ошибка: показать карточку с подписью «Це ластівка», повторить вопрос через одну карточку, а не сразу.

Готово: сцена считается пройденной, если L1–L3 правильно без подсказки. Прогресс по сценам и по персонажам хранится локально.

## 6. Экраны MVP

1. **Главный:** список сцен 1–8, у каждой значок прогресса. Кнопка «Пари» отдельно.
2. **Сцена:** картинка, кнопка 🔊 повторить, кнопка 🐢 медленнее, вопрос, поле ответа (голос или выбор). Кнопка «Підказка» показывает подсказку по уровню.
3. **Переказ:** экран с 3 картинками сцены, игрок говорит пересказ, приложение показывает эталон.
4. **Родитель:** пароль-пример (простая задачка), список сцен, ошибки, сброс.

Экраны должны работать в вертикальной и горизонтальной ориентации, от iPhone SE до iPad. Крупные кнопки, один вопрос на экран.

## 7. Речь

- Вывод голоса: `speechSynthesis`, язык `uk-UA`. Проверить наличие украинского голоса на iPhone и iPad, дать выбор голоса в настройках. Если голоса нет, текст читает родитель, приложение показывает текст.
- Распознавание: `SpeechRecognition` / `webkitSpeechRecognition`, `lang='uk-UA'`, `maxAlternatives=5`. Поддержка украинского в Safari не проверена, это главный риск. Если распознавание недоступно, работают режимы «Выбор» и «Родитель».
- Для MVP достаточно правильного ответа: нормализация строки (нижний регистр, без апострофа и знаков), сравнение со списком допустимых ответов в данных.

## 8. Данные

Файлы в репозитории:

- `data/works.json`: список творів підручника (бібліотека): `id`, `title`, `author`, `kind` (prose, tale, poem), `cover`, кількість сцен, `status: "soon"` для ще не готових, `map` для твору з картою.
- `data/works/<id>/scenes.json`: сцени твору. Поля: `num`, `title`, `summary` (наш пересказ), `stage`, `questions` (L1–L3), `frames` (3 кадри переказу), а також `pairs` для режиму «Пари».
- `data/works/<id>/characters.json`: персонажі твору. Поля: `name`, `img`, `features`, `poses`.
- `images/`: свои SVG или PNG, по одной картинке на персонажа и на сцену.

Имя файла данных не содержит персональных данных. Прогресс хранится в `localStorage` в блоке try/catch, без аккаунта, без сервера. Экспорт и импорт прогресса в JSON.

## 9. Технические требования

- Статический сайт: HTML, CSS, JS, без сервера и без сборки, если можно. GitHub Pages, HTTPS обязателен (нужен для микрофона).
- PWA: установка на экран, офлайн после первой загрузки. Речь может требовать сеть на iOS.
- Браузеры: Safari на iPhone и iPad (основные устройства), Chrome на Mac.
- Тесты: нормализатор ответов (таблица ввод → ожидание), Playwright smoke-тест в режиме «Выбор» (сцена 1 пройдена, прогресс сохранён), ручная проверка на iPhone Safari.

## 10. Критерии приёмки MVP

- [ ] Все 8 сцен открываются, картинки и вопросы на месте.
- [ ] Режим «Выбор» работает на iPhone Safari без распознавания речи.
- [ ] Режим «Пари» показывает пары из раздела 4 и даёт подсказку при ошибке.
- [ ] Ответ голосом работает хотя бы для L1 на iPhone, или в документе зафиксировано, что не работает.
- [ ] Прогресс сохраняется после перезагрузки страницы.
- [ ] Родительский экран показывает ошибки и умеет сбросить прогресс.
- [ ] В репозитории нет текста и картинок из учебника, нет имени ребёнка.

## 11. Не входит в MVP

Все остальные сказки учебника, проверка письменного пересказа, пересказ по памяти без подсказок, статистика по времени, синхронизация между устройствами, аккаунты.

## 12. Открытые вопросы (отвечает Кондрат, рекомендуемый ответ в скобках)

1. Голос выводить на украинском или дать выбор русского для подсказок? (Украинский для всего, русский только для родителя.)
2. Репозиторий публичный или приватный? Для GitHub Pages приватный репозиторий нужен платный план. (Публичный, в нём нет текста учебника и данных ребёнка.)
3. Сколько по времени одна сессия? (10 минут, 3 сцены.)
4. Нужны ли картинки от ребёнка, например он сам рисует персонажей? (Да, как вариант в следующей версии.)
