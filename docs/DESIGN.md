# Дизайн: «Переказ» (MVP «Щасливий принц»)

Дополнение к `SPEC.md` проекта `pereskaz-trainer`. Описывает внешний вид, интерактив и картинки. Где этот файл расходится со SPEC.md по функциям, прав SPEC.md. Где расходится по виду, прав этот файл.

Основа: дизайн-система проекта «Помаранчева тривога» (Orange Alert). Оттуда берём:
- токены цветов на `:root` и тёмную тему;
- большую «статус-карточку» сверху экрана;
- чипы-фильтры и нижнюю таб-панель;
- выезжающую снизу шторку (sheet) по тапу на объект;
- интерактивный центральный объект, который крутится и тянется пальцем: там глобус, здесь карта города.

Всё это переодеваем для сказки и ребёнка.

---

## 0. Для Claude Code: как работать с этим файлом

1. Прочитай целиком вместе с SPEC.md.
2. Сначала сделай **мокап главного экрана** (раздел 4.1) с картой города и двумя готовыми картинками (Ластівка и Дівчинка з сірниками). Покажи Кондрату и жди «ок».
3. Только потом рисуй остальные картинки (раздел 6) и экраны.
4. Картинки учебника не смотри и не копируй. Рисуй по описаниям из раздела 6.

## 1. Идея одной строкой

Главный экран — это **живая карта города Щасливого принца**. В центре на колонне стоит статуя. Вокруг 8 мест, по одному на сцену. Пройденная сцена «загорается», и к ней пролетает Ластівка. Прогресс видно буквально: Принц раздаёт золото городу.

Механика прогресса совпадает с сюжетом:
- с каждой пройденной сценой с Принца улетает листок золота;
- в доме, куда он попал, зажигается тёплое окно.

Пройти всё значит, что город светится, а статуя серая. Финальный экран сцены 8 показывает свинцевое серце и пташку в свете.

## 2. Токены (CSS custom properties)

Цвета задаём только токенами на `:root`, тёмная тема переопределяет их (как в Orange Alert):
- `@media (prefers-color-scheme: dark)` для `:root:not([data-theme="light"])`;
- и отдельно `:root[data-theme="dark"]`.

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `--bg` | `#F6F1E7` (пергамент) | `#121826` | фон страницы |
| `--surface` | `#FFFFFF` | `#1C2436` | карточки |
| `--ink` | `#1E2433` | `#EEF1F7` | основной текст |
| `--ink-soft` | `#5B6475` | `#A9B1C2` | подписи |
| `--night` | `#22304F` | `#0B1020` | небо на карте, шапка |
| `--gold` | `#E8B23A` | `#F2C04E` | золото, прогресс, главный акцент |
| `--gold-deep` | `#B9821C` | `#D79E2A` | тени золота, обводка активного |
| `--sapphire` | `#2F6FD6` | `#5B93F0` | кнопки действий, ссылки |
| `--ruby` | `#C2415A` | `#E0647B` | только рубин и сердце, **не для ошибок** |
| `--reed` | `#6E9F5A` | `#8CBF76` | «правильно», Очерет, трава |
| `--snow` | `#E9EEF5` | `#2A3349` | зима, неактивное |
| `--hint` | `#FFF4D6` | `#3A3320` | фон подсказки |
| `--radius` | `20px` | | карточки |
| `--radius-lg` | `28px` | | главная карточка, шторка |
| `--shadow` | `0 6px 20px rgb(30 36 51 / .12)` | `0 6px 20px rgb(0 0 0 / .4)` | |

**Ошибка никогда не красная.** Вместо этого мягкая подсказка цвета `--hint` с картинкой правильного ответа. Как в Orange Alert «не похоже на тревогу», здесь «не похоже на двойку».

**Шрифты (Google Fonts, оба с кириллицей):**
- заголовки: `Rubik` 600/700;
- текст: `Nunito` 400/600/800.
- Размер текста не меньше 18px, вопрос 26–32px, кнопка ответа 22px.

## 3. Компоненты

| Компонент | Откуда в Orange Alert | Как выглядит здесь |
|---|---|---|
| **Карточка сцены** (верх главного) | карточка уровня тревоги | Номер и название текущей сцены, маленькая картинка, прогресс «L1 ✓ L2 ✓ L3 …», кнопка «Продовжити» |
| **Карта города** | глобус | Раздел 5 |
| **Шторка места** | шторка региона по тапу | Тап по месту на карте: картинка сцены, 1 фраза пересказа (скрыта до прохождения), кнопки «Грати», «Переказ» |
| **Карточка персонажа** | карточки-счётчики «как игральные карты» | Вертикальная карта 3:4, большая картинка, имя снизу на ленте. На обороте признаки («у неї крила»). Переворот 3D по тапу |
| **Чипы** | чипы тем/регионов | Режимы «Хто це? / Що робить? / Чому? / Порядок / Переказ», «Пари» |
| **Нижняя панель** | таб-бар | 🏙 Місто · 🃏 Картки · 🔁 Пари · 👤 Батькам. Иконки свои SVG, не эмодзи |
| **Кнопки речи** | — | Круглые 64px: 🔊 повторити (`--sapphire`), 🐢 повільніше, 🎤 відповісти (пульсирует золотым кольцом, пока слушает) |
| **Подсказка** | строка «Підстава: …» под статусом | Плашка `--hint` с иконкой лампочки. Появляется снизу, не закрывает картинку |

Размеры:
- тап-цели не меньше 56×56px;
- между ответами не меньше 12px;
- на экране один вопрос.

## 4. Экраны

### 4.1 Главный «Місто» (мокап сначала)

```
┌───────────────────────────────┐
│ ✨ Переказ   [🌙] [⚙︎]        │  шапка --night, золотой логотип-листок
├───────────────────────────────┤
│ ┌───────────────────────────┐ │
│ │ [картинка] Сцена 3        │ │  карточка сцены
│ │ Ніч під статуєю           │ │
│ │ ● ● ○ ○ ○   [Продовжити →]│ │
│ └───────────────────────────┘ │
│                               │
│   ╭─── КАРТА ГОРОДА ───╮      │  ~55% высоты экрана
│   │ дома, река, статуя │      │  drag / pinch, тап по месту
│   ╰────────────────────╯      │
│  Золота роздано: ▮▮▮▯▯▯▯▯ 3/8 │  листочки, а не полоска
├───────────────────────────────┤
│  🏙 Місто  🃏 Картки 🔁 Пари 👤│
└───────────────────────────────┘
```

На iPad и в горизонтальной ориентации карта уходит влево (60%), а карточка сцены и прогресс вправо колонкой.

### 4.2 Сцена (вопрос)

- Сверху большая картинка сцены, 16:10.
- Персонаж, о котором спрашиваем, мягко подсвечен золотым контуром. Остальное чуть приглушено (`filter: saturate(.6)`).
- Под картинкой вопрос крупно и две кнопки речи 🔊 🐢.
- Ответ:
  - режим «Вибір»: 3 карточки персонажей в ряд (на SE в столбик);
  - режим «Голос»: большая 🎤 и под ней распознанный текст.
- «Підказка» — это текстовая кнопка снизу, а не на виду. Подсказки идут по уровням SPEC 5.

### 4.3 Правильно / ошибка

**Правильно:**
1. Карточка ответа подпрыгивает (scale 1 → 1.06 → 1, 250 мс).
2. Из угла вылетает листок золота и летит к счётчику (400 мс).
3. Звучит короткое «Так!» голосом `uk-UA`, звуки можно отключить.

**Ошибка:**
1. Неверная карточка тихо гаснет.
2. Появляется правильная с лентой «Це Ластівка» на фоне `--hint`.
3. Ластівка на картинке делает взмах крыльями.

Без звука ошибки, без красного, без тряски. Вопрос повторяется через одну карточку (SPEC 5).

### 4.4 Переказ

- Три картинки сцены в ряд, как раскадровка. Тап по картинке показывает её на весь экран.
- Внизу 🎤 и текст «Розкажи, що сталося».
- После ответа показываем эталон по фразам, и каждая фраза подсвечивает свою картинку.
- Совпавшие ключевые слова подчёркнуты `--reed`.

### 4.5 Порядок (L4)

- Три карточки сцен перетаскиваются в слоты 1-2-3.
- Слоты выглядят как кадры киноленты.
- Есть альтернатива без drag: тапнуть карточки по порядку, на них появляются цифры.

### 4.6 Пари

- Две карточки персонажей рядом, крупно.
- Вопрос «Хто це — Ластівка?»
- При ошибке обе карточки переворачиваются признаками («у неї крила» / «вона тримає сірники»). Признак подсвечен на картинке кружком.

### 4.7 Батькам

- Вход через простую задачку.
- Сдержанный вид без анимаций.
- Таблица сцен и уровней (✓ / подсказка / ошибка).
- Список путаемых пар с числом ошибок.
- Кнопки «Скинути прогрес», «Експорт / Імпорт JSON», выбор голоса.

## 5. Интерактивная карта города (центральный объект)

Аналог глобуса из Orange Alert: он тоже крутится, тянется пальцем, места подсвечиваются, по тапу открывается шторка.

**Техника:**
- Один inline SVG `viewBox="0 0 1200 900"`, без библиотек.
- Перетаскивание и зум через Pointer Events: pan + pinch, зум от 1× до 2,5×, инерция 300 мс.
- Двойной тап возвращает вид к началу.
- Ограничение по краям, чтобы карта не уезжала.

**Слои (отдельные `<g id>`):**
1. `sky`: небо, градиент `--night` → тёплый у горизонта. Ночью звёзды. В сцене 6 падает снег, это CSS-анимация 40 снежинок, отключаемая при `prefers-reduced-motion`.
2. `river`: река с очеретом слева, для сцены 2.
3. `city`: 12–15 домов в плоском стиле с 2–3 оттенками на грань и черепичными крышами. У каждого дома свои окна `<rect class="win">`. Пока сцена не пройдена, окна тёмные, после прохождения они становятся `--gold` со свечением `filter: drop-shadow`.
4. `places`: 8 мест-«хотспотов» (таблица ниже). Каждое — группа с картинкой-значком, номером в кружке и невидимой тап-зоной не меньше 72px.
5. `statue`: колонна в центре и Принц. У Принца 8 листков золота, которые по мере прогресса исчезают по одному. Сапфировые глаза поблёскивают, рубин на шпаге виден, пока не пройдена сцена 4.
6. `swallow`: Ластівка — отдельный `<symbol>` с анимируемыми крыльями. После прохождения сцены она летит по `<path>` от статуи к месту сцены и обратно. Полёт сделан через `offset-path` или ручную интерполяцию, около 1,6 с.

| № | Место на карте | Что подсветить |
|---|---|---|
| 1 | Площа зі статуєю (центр) | постамент, радник рядом |
| 2 | Річка з очеретом (слева) | очерет колышется |
| 3 | Статуя вночі, дощ | капли и слеза Принца |
| 4 | Будиночок кравчині | окно со швейной машинкой, апельсин |
| 5a | Мансарда драматурга | окно под крышей, свеча |
| 5b | Ріг вулиці, дівчинка з сірниками | огонёк спички |
| 6 | Зимові вулиці | снег, дети у фонаря |
| 7 | Ратуша / піч | дым, мер с радниками |
| 8 | Небо над містом (вверху) | ангел, луч света |

**Состояния места:**
- *закрито*: серое (`--snow`), без номера;
- *доступно*: золотой кружок с номером и лёгкая пульсация, как у Украины в Orange Alert. Пульсирует только одно, следующее;
- *пройдено*: окно горит, рядом лежит листок золота.

**Доступность:**
- у каждого места `role="button"` и `aria-label="Сцена 4. Рубін для кравчині. Пройдено"`;
- навигация Tab / Enter;
- под картой есть кнопка «Список сцен», она открывает обычный список: это текстовая альтернатива карте.

## 6. Картинки: стиль и список

### 6.1 Стиль

- **Плоская детализированная иллюстрация в SVG**: не «иконка в кружке», а маленькая книжная картинка.
- На каждый цвет 3 оттенка: свет, база, тень. Мягкие тени делаются полупрозрачными фигурами, а не фильтрами, чтобы быстро работало на iPhone.
- Контур `--ink` 2.5px с `stroke-linejoin: round`, одинаковый во всех картинках.
- Холст персонажа `viewBox="0 0 300 400"`, сцены `0 0 640 400`.
- Лица простые, но живые: глаза-овалы с бликом, брови передают эмоцию. Это нужно для вопросов L3 «Що відчуває?».
- Каждый персонаж в 3 позах: `neutral`, `action` (что делает), `emotion` (что чувствует). Позы — отдельные `<symbol>` в одном спрайте `images/characters.svg`, лицо и руки меняются, силуэт тот же.
- Анимируемые части вынесены в отдельные группы с id: `#wing-l`, `#wing-r`, `#eye-blink`, `#tear`, `#flame`. Анимация идёт через CSS transform-origin и отключается при `prefers-reduced-motion`.
- Вес: одна картинка персонажа до 25 КБ, сцена до 60 КБ. Минифицировать через SVGO.

### 6.2 Различимость путаемых пар (главное для этого ребёнка)

Каждую пару различаем **тремя каналами сразу**: силуэт, цвет и предмет в руках.

| Пара | Персонаж А | Персонаж Б |
|---|---|---|
| Ластівка / Дівчинка | **Ластівка**: маленькая птица, сине-чёрная спинка, белая грудка, длинный раздвоенный хвост, крылья всегда видны. Горизонтальный силуэт | **Дівчинка з сірниками**: девочка в полный рост, красный платок и рваная коричневая шаль, коробка спичек в руках, босая. Вертикальный силуэт |
| Принц / Мер | **Принц**: статуя на постаменте, золотой с отблесками, синие глаза-сапфиры, шпага с рубином, неподвижная поза | **Мер**: живой полный мужчина, тёмно-синий камзол, широкая лента через плечо, цепь на шее, шляпа. Жестикулирует |
| Кравчиня / Дівчинка | **Кравчиня**: взрослая женщина, зелёный фартук, напёрсток и иголка с ниткой, сидит. Рядом кровать с хлопчиком | **Дівчинка**: см. выше. Ребёнок, стоит на улице, ночь |
| Очерет / Ластівка | **Очерет**: высокий тонкий стебель с пушистой метёлкой, зелёный, растёт из воды, наклоняется | **Ластівка**: см. выше. Летит |

На обороте карточки персонажа 2–3 признака текстом, и на картинке они обведены кружком, например «💬 у неї крила» и «💬 хвіст як ножиці».

### 6.3 Список картинок для MVP

**Персонажи** (12, по 3 позы):
- Щасливий принц;
- Ластівка;
- Очерет;
- Мер міста;
- Міські радники (группа из 2–3, один силуэт);
- Кравчиня;
- Синок кравчині;
- Драматург;
- Дівчинка з сірниками;
- Професор орнітології;
- Ангел;
- Бог — **не изображаем лицо**: показываем луч света и руку или только свет. Это мягче и не спорно.

**Предметы** (7, по одной картинке): листок золота, сапфір, рубін, сірники, апельсини, свинцеве серце, мертва пташка. Пташку рисуем спящей, со сложенными крыльями, без натурализма.

**Сцены** (8, по 3 кадра для пересказа = 24): композиция из готовых `<use>` персонажей поверх фона места с карты. Это экономит работу и держит стиль единым.

### 6.4 Процесс рисования

1. Сначала Ластівка и Дівчинка з сірниками, обе в позе neutral, и показать Кондрату вместе с мокапом карты.
2. После «ок» остальные персонажи в neutral, затем позы.
3. Сцены собираются из персонажей и фонов.

Если Кондрат захочет картинки ребёнка (SPEC 12.4), карточка поддерживает замену `image` на PNG/JPG без изменения разметки.

## 7. Движение и звук

| Что | Длительность | Easing |
|---|---|---|
| Открытие шторки | 280 мс | `cubic-bezier(.2,.8,.2,1)` |
| Переворот карточки | 450 мс | тот же |
| Пульс доступного места | 1,8 с, бесконечно | `ease-in-out` |
| Полёт ластівки | 1,6 с | `ease-in-out` |
| Листок золота к счётчику | 400 мс | `ease-out` |

- `prefers-reduced-motion: reduce` отключает всё движение, кроме мгновенной смены состояний.
- Звуки (короткое «дзинь» золота, шелест крыльев) включены по умолчанию и отключаются в настройках. Громкость тише голоса.

## 9. Чего не делать

- Не использовать иллюстрации учебника и не «перерисовывать по ним».
- Не делать красный цвет и тряску для ошибок, а также звуки «неправильно».
- Не показывать имя, фото или возраст игрока (SPEC 0).
- Не тащить тяжёлые библиотеки (three.js, Lottie) ради карты: хватает SVG и CSS.

## 10. Критерии приёмки дизайна

- [ ] Мокап главного экрана с картой одобрен Кондратом.
- [ ] Карта тянется и зумится пальцем на iPhone и не тормозит (60 fps на iPhone 12+).
- [ ] Все 8 мест открывают шторку, у мест есть текстовая альтернатива.
- [ ] Пары из SPEC 4 различимы по силуэту без цвета (проверка: скриншот в оттенках серого).
- [ ] Светлая и тёмная темы, iPhone SE и iPad portrait/landscape без поломок.
- [ ] `prefers-reduced-motion` отключает анимации.
