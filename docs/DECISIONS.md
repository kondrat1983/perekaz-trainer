# Решения по проекту

Открытые вопросы из SPEC.md, раздел 12. У каждого указан рекомендуемый ответ из спецификации и ответ владельца (Кондрат).

## 1. Язык голоса и подсказок

- **Рекомендация:** украинский для всего, русский только для родителя.
- **Ответ владельца:** украинский для всего (рекомендация принята).
- **Следствие:** русский нужен только на родительском экране. В настройках голоса — выбор украинского голоса.

## 2. Репозиторий публичный или приватный

- **Рекомендация:** публичный (в нём нет текста учебника и данных ребёнка).
- **Ответ владельца:** публичный (рекомендация принята).
- **Следствие:** GitHub Pages работает бесплатно. Персональные данные и текст учебника в репозиторий не попадают (см. CLAUDE.md).

## 3. Длительность одной сессии

- **Рекомендация:** 10 минут, 3 сцены.
- **Ответ владельца:** без лимита.
- **Следствие:** в MVP нет таймера и ограничения по сценам за сессию. Игрок сам решает, когда остановиться.

## 4. Картинки от ребёнка

- **Рекомендация:** да, как вариант в следующей версии.
- **Ответ владельца:** нет.
- **Следствие:** в MVP все картинки делаем сами (SVG). Вопрос не входит в MVP и не запланирован на следующую версию.

## 5. Сборка MVP («Щасливий принц»)

Мокап главного экрана одобрен. Сборка идёт только для сказки «Щасливий принц».

- **Голос:** `speechSynthesis` с языком uk-UA. Голос по умолчанию: Lesya, если установлена (в iOS можно скачать Enhanced). В «Батькам» есть выбор голоса. Если украинского голоса нет, текст показывается и его читают вслух родители. Предзаписанные нейро-голоса (Azure) пока не подключены: решение ждёт ответа владельца.
- **Карта:** главный экран по DESIGN.md 4.1. Места открываются по порядку: сцена N открыта, когда пройдена сцена N−1. В «Батькам» есть переключатель «Відкрити всі сцени».
- **Стиль картинок:** владелец выбрал «аплікацію з паперу» из 10 образцов ластівки. Плоские куски бумаги без контуров, у каждого куска тень, небо полосами. Правила в скилле `.claude/skills/illustrator`.
- **Картинки:** 7 персонажей (Принц, Мер, Ластівка, Очерет, Кравчиня, Дівчинка з сірниками, Ангел), 11 предметов и накладка дождя (`images/items/`), 5 фонов (город, река, комната кравчини, зима, небо). Бог показан только светом, без лица. Мёртвая пташка нарисована спящей.
- **Переказ:** у каждой сцены 3 кадра, собранные в данных из персонажей и предметов поверх фона. Фразы кадров вместе дают эталонный переказ. Тап по кадру открывает его на весь экран, тап по фразе подсвечивает кадр и читает фразу вслух. Слова эталона, которые Игрок сказал сам, подчёркиваются.
- **Пари:** 4 пары из SPEC 4. Ошибка: показываем правильную карточку с подписью «Це ластівка» и её признаками, вопрос возвращается через одну карточку.
- **Вибір:** L1–L3 по одному вопросу за раз. Ошибка не красная: подсказка и повтор через одну карточку. Сцена пройдена, если L1–L3 верны без подсказки.
- **Голосовой ответ:** только для L1 и только если браузер поддерживает распознавание (SpeechRecognition).
- **Прогресс:** localStorage в try/catch, экспорт и импорт JSON.
- **Тесты:** `npm test`. Юнит-тесты нормализатора и два Playwright-сценария (проход сцены 1 с сохранением прогресса, гейт родителя).
- **Не проверено в этой сборке:** Пари и голосовой ответ не покрыты автотестами и не проверены на iPhone. Офлайн-режим тоже не проверен на устройстве.
